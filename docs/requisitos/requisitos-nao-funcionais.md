# Requisitos Não Funcionais

## RNF01
A interface deve ser intuitiva, apresentar linguagem adequada e facilitar a utilização por crianças dos anos iniciais do Ensino Fundamental.

## RNF02
O sistema deve utilizar elementos visuais e uma organização clara das informações para facilitar a compreensão das atividades matemáticas.

## RNF03
O sistema deve fornecer retorno visual às ações realizadas pelo usuário, indicando resultados, confirmações e possíveis erros.

## RNF04
O sistema deve apresentar mensagens adequadas quando ocorrerem falhas de comunicação com o servidor ou indisponibilidade de serviços.

## RNF05
O sistema deve ser compatível com os principais navegadores modernos.

## RNF06
A interface deve adaptar-se a diferentes tamanhos de tela, permitindo a utilização em computadores e tablets.

## RNF07
O código-fonte deve apresentar organização modular, facilitando a manutenção, a identificação de componentes e futuras atualizações.

## RNF08
O sistema deve proteger os dados dos usuários por meio de armazenamento seguro de senhas, autenticação e controle de acesso às funcionalidades restritas.

## RNF09
O sistema deve preservar a integridade das informações de desempenho e progresso dos alunos, mantendo a associação entre usuários, atividades e tentativas registradas.

## RNF10
A arquitetura deve permitir a inclusão de novas atividades e conteúdos matemáticos sem exigir uma reformulação completa do sistema.

## RNF11
O frontend deve ser desenvolvido utilizando JavaScript e React, o backend utilizando Python e FastAPI e o armazenamento de dados utilizando PostgreSQL.
