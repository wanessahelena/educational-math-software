# Requisitos Não Funcionais

## RNF01
A interface deve ser intuitiva e adequada para crianças dos anos iniciais do Ensino Fundamental.

## RNF02
O sistema deve utilizar elementos visuais que facilitem a compreensão das atividades pelos alunos.

## RNF03
As ações do usuário devem apresentar resposta em até 2 segundos.

## RNF04
O sistema deve estar disponível durante todo o período de utilização escolar.

## RNF05
O sistema deve funcionar nos principais navegadores modernos.

## RNF06
A ferramenta deve ser acessível em computadores e tablets.

## RNF07
O código-fonte deve ser modular para facilitar futuras atualizações.

## RNF08
Os dados dos usuários devem ser armazenados de forma segura.

## RNF09
O sistema deve garantir a integridade das informações de progresso dos alunos.

## RNF10
A arquitetura deve permitir a inclusão de novos conteúdos matemáticos e novas fases sem necessidade de reformulação completa do sistema.

## RNF11
O front-end deve ser desenvolvido utilizando JavaScript e React, o back-end utilizando Python e os elementos gamificados utilizando Godot.
