# Requisitos de Sistema

## RF01
O sistema deve permitir o cadastro de alunos, mediante o fornecimento de nome, e-mail, senha e ano escolar.

## RF02
O sistema deve permitir que alunos cadastrados realizem login e logout.

## RF03
O sistema deve permitir ao aluno selecionar seu ano escolar durante o cadastro e atualizá-lo posteriormente em seu perfil.

## RF04
O sistema deve permitir ao aluno visualizar e selecionar as atividades matemáticas disponíveis para seu ano escolar.

## RF05
O sistema deve disponibilizar uma interface interativa para a resolução das atividades matemáticas propostas.

## RF06
O sistema deve validar a resposta final fornecida pelo aluno, comparando-a com a resposta esperada da atividade.

## RF07
O sistema deve informar automaticamente ao aluno se sua resposta está correta ou incorreta.

## RF08
O sistema deve registrar o histórico de tentativas realizadas pelo aluno nas atividades matemáticas.

## RF09
O sistema deve apresentar informações sobre o desempenho do aluno, incluindo atividades realizadas, acertos e progresso.

## RF10
O sistema deve disponibilizar, por meio da API, funcionalidades para cadastrar e consultar atividades matemáticas.

## RF11
O sistema deve permitir que o aluno consulte e atualize seus dados de perfil, incluindo nome e ano escolar.

## RF12
O sistema deve permitir a alteração de senha mediante a confirmação da senha atual.

## RF13
O sistema deve permitir a recuperação de senha por meio de um link temporário enviado ao e-mail cadastrado.

## RF14
O sistema deve exigir a verificação do endereço de e-mail informado durante o cadastro, antes de permitir o acesso do aluno.

## RF15
O sistema deve permitir o reenvio do link de verificação de e-mail.

## RF16
O sistema deve permitir a alteração do endereço de e-mail cadastrado, mediante confirmação da senha atual e verificação do novo endereço de e-mail.

## RF17
O sistema deve permitir o gerenciamento de registros de usuários por meio dos recursos administrativos disponibilizados pela API, quando implementados.
