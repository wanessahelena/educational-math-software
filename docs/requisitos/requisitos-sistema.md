# Requisitos de Sistema

## RF01
O sistema deve permitir o cadastro de alunos.

## RF02
O sistema deve permitir login e logout dos usuários.

## RF03
O aluno deve poder selecionar o ano escolar correspondente ao seu nível de ensino.

## RF04
O sistema deve permitir ao aluno escolher fases ou desafios disponíveis.

## RF05
O sistema deve disponibilizar uma interface para montagem de algoritmos utilizando blocos visuais.

## RF06
O sistema deve executar o algoritmo criado pelo aluno.

## RF07
O sistema deve verificar automaticamente se a solução proposta está correta.

## RF08
O sistema deve registrar pontos obtidos pelo aluno.

## RF09
O sistema deve desbloquear novos desafios conforme o progresso do usuário.

## RF10
O sistema deve armazenar o histórico de desempenho do aluno.

## RF11
O sistema deve apresentar informações sobre desempenho, acertos e progresso.

## RF12
O sistema deve permitir cadastrar e atualizar atividades matemáticas.

## RF13
O sistema deve permitir criar e editar fases do jogo educacional.

## RF14
O sistema deve permitir a administração dos usuários cadastrados.
